# Images

Drop all site images in this directory. Use the filenames below so HTML
references stay consistent. Recommended formats: `.webp` or `.jpg` for
photos, `.svg` for icons/logo.

## Brand

| Filename | Purpose | Recommended size |
|----------|---------|------------------|
| `logo.svg` | Primary logo (header/footer) | vector, ~160×40 |
| `logo-mark.svg` | Circular monogram mark | vector, ~40×40 |
| `favicon.svg` | Browser tab icon | vector, 32×32+ |
| `og-image.jpg` | Open Graph social share image | 1200×630 |

## Hero / lifestyle

| Filename | Purpose | Recommended size |
|----------|---------|------------------|
| `hero-cake.jpg` | Home hero photo | ~1200×1500 (4:5) |
| `hero-kitchen.jpg` | Alt hero / about story | ~1000×800 (5:4) |
